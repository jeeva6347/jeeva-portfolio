# 💼 Personal Portfolio Website

A modern and responsive portfolio website built with **React.js** to showcase my skills, projects, education, and contact information.

---

## ✨ Features

- 👋 Home section
- 🙋 About Me
- 🛠️ Skills section
- 💼 Projects showcase
- 📞 Contact section
- 📱 Fully responsive design
- ⚡ Smooth user experience

---

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/jeeva6347/portfolio.git
```

### Navigate to the Project

```bash
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```
